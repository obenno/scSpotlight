<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| R producer → manifest | R payload fields and IPC columns must satisfy the explicit contract. |
| Session resource path → browser fetch | Browser fetches IPC files by resource basename under `/data/{kind}/`. |
| Browser cache → plot state | Cached cold IPC buffers are rehydrated into typed arrays used by scatter and floating panels. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-05 | Information Disclosure | Browser payload file fields | mitigate | Manifest and R tests require browser messages to carry basenames only and reject path-like fields such as `matrix_dir` or `output_file`. |
| T-01-06 | Tampering | Payload schema drift | mitigate | R and JS tests both consume `inst/protocol/browser-payload-contracts.json` so field changes fail producer/consumer verification. |
| T-01-07 | Denial of Service | Stale cache-version behavior | mitigate | JS tests assert older `reductionVersion`/`exprVersion` payloads are ignored and newer versions clear stale buffers. |
| T-01-08 | Information Disclosure | Raw data / large matrix exposure | mitigate | IPC column assertions limit browser transfers to scoped vectors/tables: `cells`, requested metadata cols, `X`/`Y`, `stdev`, and requested-gene `expr`. |
| T-01-SC | Tampering | Package installs | accept | This plan uses existing `jsonlite`, testthat, and Vitest dependencies and installs no packages. |
</threat_model>
