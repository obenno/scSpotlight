<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Seurat/BPCells object → R helper seam | In-memory Analysis object data enters helper functions that produce browser-readable payloads. |
| R helper seam → session temp files | Arrow IPC files are written under the Shiny session temp resource path. |
| R module → browser message | Browser receives file basenames and version metadata via `session$sendCustomMessage()`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | `prepare_backend_expression_transfer()` payload | mitigate | Contract tests assert browser payloads expose `exprFile` basenames and version fields, not local `matrix_dir` paths or live object fields. |
| T-01-02 | Tampering | Analysis runtime source selection | mitigate | Source assertions block DuckDB runtime calls in Analysis transfer adapter and expression module files. |
| T-01-03 | Denial of Service | Expression transfer futures | mitigate | Tests preserve path-based queued expression jobs so futures do not carry live Seurat/BPCells objects or trigger overlapping matrix materialization. |
| T-01-04 | Information Disclosure | Metadata/reduction helper output | mitigate | Tests require Arrow IPC schemas scoped to browser contract columns rather than full object serialization or local paths. |
| T-01-SC | Tampering | Package installs | accept | This plan installs no npm, pip, cargo, R, or system packages. |
</threat_model>
