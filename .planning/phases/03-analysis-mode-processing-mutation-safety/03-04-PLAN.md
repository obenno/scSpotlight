<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser selected cells → subset server | Client-selected cell IDs determine server-side object replacement. |
| Subset switch state → original object backup | User toggles control storing/restoring canonical Seurat object state. |
| Object replacement → browser caches | New metadata/reduction/feature state must invalidate previous selection and expression cache state. |
| Restore lifecycle → downstream transfer producers | Restored object triggers existing Arrow IPC producers for metadata, reductions, expression, and plot refresh. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-16 | Tampering | stale/invalid subset selected cells | mitigate | `mod_SubsetCells_server()` uses safe subset helper validation and rejects empty intersections before object mutation. |
| T-03-17 | Tampering | original object backup lifecycle | mitigate | Tests enforce original stored once, restored once, cleared after restore, and repeated toggles are safe no-ops. |
| T-03-18 | Denial of Service | subsetted object dense state | mitigate | Safe helper preserves BPCells backing where available and drops final dense `scale.data` after subset. |
| T-03-19 | Tampering | stale browser selection/expression cache | mitigate | JS tests and implementation clear/reconcile selected cells, rename payloads, expression cache, and feature state after object replacement. |
| T-03-20 | Information Disclosure | subset/restore notifications and transfer errors | mitigate | Notifications are path-free and existing `transfer_error` contract remains sanitized for transfer failures. |
| T-03-SC | Tampering | Package installs | accept | This plan installs no npm, pip, cargo, R, or system packages. |
</threat_model>
