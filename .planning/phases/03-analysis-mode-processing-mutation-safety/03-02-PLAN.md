## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User-selected/stale cell IDs → Seurat subset | Browser or reactive selection IDs drive server-side object filtering. |
| Cluster controls → Seurat processing | User-selected dimensions/resolution/HVG method mutate reductions, graphs, and metadata. |
| Cell-cycle scoring errors → Shiny notifications | R scoring failures can cross into user-visible copy. |
| Metadata mutation → `meta_patch_ready` | New cell-cycle columns are transferred through existing column-scoped patch IPC. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06 | Tampering | filter/subset selected-cell IDs | mitigate | `safe_subset_seurat_object()` validates/intersects cells, preserves source order, and fails before mutation when no valid cells remain. |
| T-03-07 | Denial of Service | filter and cluster processing | mitigate | Reuse Plan 03-01 no-final-dense-scale helpers after filtering and cluster updates; tests block persisted `scale.data`. |
| T-03-08 | Denial of Service | cell-cycle metadata transfer | mitigate | Use `metaPatchRequest` for only `S.Score`, `G2M.Score`, and `Phase` instead of full metadata reloads. |
| T-03-09 | Information Disclosure | cell-cycle/filter/cluster notifications | mitigate | Browser-visible error copy is generic/path-free; raw conditions are not pasted into notifications. |
