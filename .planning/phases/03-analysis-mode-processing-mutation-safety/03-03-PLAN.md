## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser lasso/category selection → Shiny selected-cell payload | Client-side selected cell IDs are submitted for server-side metadata assignment. |
| Browser assignment intent → Seurat metadata | User-derived assignment intent is resolved against canonical Seurat metadata before mutation. |
| Metadata labels → browser DOM | Group/split labels and assignment values render in selector UI and status text. |
| Category context → assignment target set | Current group/split state determines category-selected cells. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-11 | Tampering | stale rename/category selections | mitigate | JS tests and implementation clear rename state on group/split changes, metadata patch invalidation, assignment completion, and deselect. |
| T-03-12 | Tampering | assignment intent shape | mitigate | Browser and R validators enforce safe column/value, current context, selected-cell identity or category context, and reject full-vector metadata before `AddMetaData()`. |
| T-03-13 | Information Disclosure | assignment/validation error copy | mitigate | Notifications and DOM updates use path-free generic copy and `textContent`; no raw paths, stack traces, or untrusted HTML. |
| T-03-14 | Denial of Service | assignment transport | mitigate | Send bounded assignment intent, mutate server-side, and return one assigned column through `meta_patch_ready` instead of full metadata JSON payloads or full reloads. |
| T-03-15 | Tampering | lasso/category precedence | mitigate | Tests define deterministic lasso-over-category precedence and current-context category fallback. |
| T-03-SC | Tampering | Package installs | accept | This plan installs no npm, pip, cargo, R, or system packages. |
</threat_model>
