<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Expression IPC decode → scatter model | Browser-decoded expression data changes main scatter color state. |
| Metadata mutation → metadata patch IPC | Server-generated column-scoped patch payloads mutate browser metadata state. |
| Browser decoded patch/expression → UI state | Decoded data changes plot colors, metadata caches, redraw decisions, legends, titles, and sparkline emphasis. |
| Feature sparkline selection → Shiny input | Browser checked order controls `selectedFeatures` and the first-gene main scatter contract. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-10 | Tampering | stale expression payload | mitigate | JS re-checks `exprVersion`, assay, and gene before cache write and before scatter mutation. |
| T-02-11 | Tampering | malformed `meta_patch_ready` payload | mitigate | `ScatterModel.validateCellMetaDataPatch()` rejects missing `{type,value}`, length mismatch, and type mismatch before merge. |
| T-02-12 | Denial of Service | full metadata reload on scoped mutation | mitigate | Patch `cols` drive targeted merge/refresh decisions instead of full metadata reloads for every mutation. |
| T-02-13 | Tampering | `featureSparkLine` selected-feature state | mitigate | Sparkline tests and implementation keep checked state, primary emphasis, Shiny `selectedFeatures`, and main scatter `selectedFeatures[0]` semantics synchronized. |
| T-02-14 | Information Disclosure | expression/patch failure copy | mitigate | Browser-visible copy uses UI-spec payload context via `textContent` and never exposes local paths, raw stack traces, matrices, or query-plan internals. |
| T-02-SC | Tampering | Package installs | accept | This plan installs no npm, pip, cargo, R, or system packages. |
</threat_model>
