## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Feature selection → R expression queue | User-controlled feature/gene names initiate scoped expression IPC jobs. |
| BPCells/DuckDB path/query plan → Arrow IPC | Backend expression reads cross into session temp Arrow IPC files without live Seurat/BPCells/Explore bundle futures. |
| R transfer job → browser payload | Path/query-plan internals are reduced to basename/version/scoped feature fields before browser notification. |
