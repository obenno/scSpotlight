## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Decoded Arrow arrays → deck.gl binary attributes | Browser-decoded data becomes GPU layer attributes. |
| User pointer input → lasso hit-testing | Untrusted pointer coordinates select cells across panel-local viewports. |
| Selection state → Shiny input | Browser-selected cell IDs are sent back to Shiny for downstream workflows. |
| Metadata/grouping state → panel layout | Metadata categories determine panel counts, titles, legends, and scroll geometry. |
